# Himalayan Taste — COM109 Client-Side Development Coursework

**Project:** A fictional Nepalese restaurant website concept based in London, United Kingdom.  
**Tagline:** A taste of the Himalayas.  
**Currency and language:** GBP (£), British English.

## Pages
- `index.html` — Home, hero banner, introduction, featured dishes and booking links.
- `about.html` — Restaurant story, concept and values.
- `menu.html` — Menu cards, category filtering and saved favourites.
- `reservations.html` — Accessible reservation request form with client-side validation and sessionStorage draft.
- `contact.html` — Contact details and validated enquiry form.

## Technologies demonstrated
- Semantic HTML5 and accessible form labels.
- External CSS3 stylesheet, Flexbox, CSS Grid, transitions, responsive media queries and reduced-motion support.
- JavaScript DOM manipulation, event listeners, validation and dynamic confirmation output.
- jQuery event handling, menu filtering and fade effects.
- `localStorage` for favourite dishes.
- `sessionStorage` for temporary reservation form progress.
- Shared favicon and image assets folder.

## How to run
1. Download and unzip the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Internet access is needed for the externally hosted food photography, Google Fonts and jQuery CDN.

## Important project limitations
This is a **client-side coursework demonstration**. Reservation and contact forms do not send data to a real restaurant or database. The restaurant address, email and menu are illustrative; replace them only if your group agrees on verified project details. Menu items, prices and allergen statements are examples and must not be represented as verified real-world restaurant information.
